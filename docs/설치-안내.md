# 결 스튜디오 설치와 실행 (팀원·테스터용)

터미널은 필요 없어요. 파일을 받아서 더블클릭하면 됩니다.

## 1. 받기

개발팀이 알려 준 링크(GitHub의 Actions 또는 Releases)에서 내 컴퓨터에 맞는 파일을 받으세요.

| 컴퓨터 | 받을 파일 |
|---|---|
| Windows 10/11 | `gyeol-studio-windows.zip` |
| Mac (M1·M2·M3 등 애플 칩) | `gyeol-studio-macos-arm64.zip` |
| Mac (인텔 칩) | `gyeol-studio-macos-x64.zip` |

## 2. 처음 실행

### Windows
1. 받은 zip 파일을 오른쪽 클릭 → **압축 풀기**. (zip 안에서 바로 실행하지 마세요.)
2. 풀린 `gyeol-studio` 폴더 안의 **gyeol-studio.exe**를 더블클릭해요.
3. "Windows의 PC 보호" 파란 창이 나오면 **추가 정보 → 실행**을 눌러요. (서명하지 않은 사내용 앱이라 나오는 안내예요.)
4. "Windows 보안 경고: 네트워크 액세스 허용" 창이 나오면 **개인 네트워크**에 체크하고 **액세스 허용**을 눌러요. 휴대폰으로 접속하려면 필요해요.

### Mac
1. 받은 zip을 더블클릭하면 **결 스튜디오** 앱이 나와요. **응용 프로그램** 폴더로 옮겨 두세요.
2. 처음 한 번은 앱을 **오른쪽 클릭(또는 control+클릭) → 열기 → 열기**로 실행해요. ("확인되지 않은 개발자" 안내가 나오는 사내용 앱이라서 그래요.)
3. "들어오는 네트워크 연결을 허용할까요?"가 나오면 **허용**을 눌러요.

### 둘 다
- 작은 창("결 스튜디오가 실행 중이에요")이 뜨고, 브라우저가 자동으로 열려요. **이 작은 창을 닫으면 앱이 꺼져요.**
- 브라우저가 안 열리면 작은 창의 **브라우저 열기**를 눌러요.
- 처음에는 보컬 분리 모델(약 640MB)을 받아요. 진행 막대가 끝까지 차면 준비 끝이에요. 인터넷이 필요한 건 이때뿐이에요.

## 3. 쓰기

1. 이름을 적고 동의 항목을 골라요.
2. **곡 추가** → 음원 파일(MP3 등)을 올려요. 보컬과 반주를 나누는 데 몇 분 걸려요.
3. 곡을 열고 파형에서 부를 부분을 끌어서 고른 뒤, 가사를 적고 **소절 저장**.
4. **연습하기** → 이어폰을 끼고 **녹음**. 딸깍 소리 4번 뒤에 따라 불러요.
5. "무엇이 달랐다고 느끼셨나요?"를 고르면 피드백이 나와요.

처음 실행하면 이 순서를 짧은 안내 투어로 보여 줘요.

## 4. 휴대폰으로 쓰기

PC와 휴대폰이 **같은 와이파이**에 있어야 해요. PC 화면 오른쪽 위의 휴대폰 모양 버튼 → QR 코드를 휴대폰 카메라로 찍어요. 처음에 "안전하지 않음" 경고가 나오면 화면 안내대로 넘어가면 돼요.

## 5. 문제가 생기면

| 증상 | 해 볼 것 |
|---|---|
| 브라우저에 "연결할 수 없음" | 작은 창이 켜져 있는지 확인. 꺼졌으면 앱을 다시 실행 |
| 마이크가 안 됨 | 주소창 옆 자물쇠 → 마이크 허용. 휴대폰은 QR 코드의 **https** 주소로 접속 |
| 보컬 분리가 오래 걸림 | 정상이에요. 4분짜리 곡이면 노트북에서 30분쯤 걸릴 수 있어요. 앱을 닫아도 다음에 이어서 해요 |
| 저장 공간 부족 | 설정 → 저장 위치에서 데이터 폴더를 다른 디스크로 옮겨요 |

계속 안 되면 화면의 오류 알림에서 **자세히 보기**를 눌러 나온 내용을 개발팀에 보내 주세요. 기록 파일은 데이터 폴더의 `logs/app.log`에 있어요.

## 6. 지우기

앱 폴더(또는 Mac의 앱)를 휴지통에 버리면 돼요. 녹음과 데이터는 데이터 폴더(기본: `문서/gyeol-studio`)에 따로 남아 있으니, 완전히 지우려면 그 폴더도 지우세요. 모델 파일은 `사용자 폴더/.cache/gyeol`에 있어요.
